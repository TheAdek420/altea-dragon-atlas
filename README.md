# Atlas Smoków — Altea

Statyczna, interaktywna strona do porównywania rozmiarów smoków i drakonidów w świecie Altei.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo wgraj **zawartość folderu** do głównego katalogu repozytorium GitHub Pages.

## Publikacja na GitHub Pages

1. Na stronie repozytorium wybierz **Add file → Upload files**.
2. Wgraj `index.html`, `style.css`, `app.js`, `data.js` i `README.md` (nie sam ZIP).
3. Kliknij **Commit changes**.
4. Otwórz **Settings → Pages**, ustaw **Deploy from a branch**, **main**, **/(root)** i naciśnij **Save**.
5. Po krótkim czasie strona powinna być pod `https://TWOJ-LOGIN.github.io/altea-dragon-atlas/`.

## Edytowanie danych

Wszystkie stworzenia znajdziesz w `data.js`. Liczby są w metrach, `null` = brak danych. To robocza skala lore, a nie bezpośredni pomiar z ilustracji.

## Ważne

Scena używa celowo uproszczonych **symbolicznych pasków**, nie prawdziwych sylwetek — nie należy traktować ich kształtu jako anatomicznej proporcji. Na kolejnych etapach można dodać zweryfikowane boczne sylwetki.
